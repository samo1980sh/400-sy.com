# 400-sy.com - Collection and Special Offer Frontend Filters

This package finalizes frontend filter UI for:

- Collection filter based on `products.collection`.
- Special offers filter based on existing import/admin logic where `top = Offer` marks `is_special_offer = true`.

No new Excel column is introduced for special offers.

Temporary package files under `tools/`, `_backup/`, and package ZIP files should not be committed.
