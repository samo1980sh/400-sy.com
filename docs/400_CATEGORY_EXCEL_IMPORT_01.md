# 400-sy.com - Category Excel Import 01

## الملفات المضافة/المعدلة

- `app/Services/CategoryImportService.php`
- `app/Filament/Resources/Categories/Pages/ListCategories.php`

## الوظائف المضافة

داخل لوحة التحكم > التصنيفات تمت إضافة:

- زر `قالب الاستيراد`
- زر `استيراد Excel`
- إبقاء زر `تصدير` الحالي كما هو

## الأعمدة المدعومة في Excel

يمكن استيراد ملف التصدير الحالي أو قالب الاستيراد. أهم الأعمدة:

- رقم التصنيف: للتحديث عند وجوده
- معرف التصنيف الأب
- Slug التصنيف الأب
- التصنيف الأب
- الاسم بالعربي
- الاسم بالانكليزي
- الرابط / Slug
- صورة بطاقة التصنيف
- بانر التصنيف
- يظهر في الصفحة الرئيسية
- الترتيب

## قواعد الاستيراد

- إذا كان رقم التصنيف موجودًا ويتم العثور عليه: يتم تحديث السجل.
- إذا لم يوجد رقم التصنيف ولكن يوجد Slug موجود: يتم تحديث السجل.
- إذا لم يوجد رقم أو Slug: يتم البحث حسب الاسم العربي + التصنيف الأب.
- إذا لم يوجد سجل مطابق: يتم إنشاء تصنيف جديد.
- صورة بطاقة التصنيف تطبق على التصنيفات الرئيسية فقط.
- البانر مسموح للتصنيفات الرئيسية والفرعية والأبناء.
- إذا تم الاستيراد وأنت داخل صفحة تصنيف أب، فالصفوف التي لا تحتوي تصنيف أب ستُضاف تحته افتراضيًا.
